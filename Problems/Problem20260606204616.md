## 任务目标

将 `Note/` 目录的 Git 策略改为只跟踪 Markdown 文档，其它文件全部忽略，避免 PDF、图片、代码、压缩包等大文件继续进入 GitHub。

## 思考过程

当前项目已经接入 Cloudflare Pages + R2，PDF 和其它大附件不应再进入 GitHub。用户要求“note中除了md文档忽略”，合理解释是：`Note/` 内保留 `.md` 文件可提交，其它所有类型都忽略。

仅修改 `.gitignore` 只能影响未跟踪文件；已经被 Git 跟踪的非 Markdown 文件仍会继续出现在提交中。因此需要同步检查已跟踪文件，并把非 `.md` 文件从索引移除，但不删除本地文件。

## 遇到的问题

- `Note/` 中已经有非 Markdown 文件被 Git 跟踪。
- 原 `.gitignore` 使用了大量按扩展名和目录枚举的规则，仍可能漏掉新增类型。
- `git add Note` 遇到嵌套 Git checkout，会被 Git 当作子模块候选处理，不能按普通目录加入。

## 解决方法

- 将 `Note/` 忽略规则改为先忽略 `Note/**`，再放开目录和 `*.md`。
- 后续执行索引清理，只从 Git 跟踪列表中移除 `Note/` 下非 `.md` 文件，本地文件保持不变。
- 对 `Note/` 里的嵌套 Git checkout 添加显式忽略规则，避免父仓库误加入本地依赖目录；其中 `yolov5/` 路径使用目录名匹配以兼容带编号的父目录。

## 验证结果

- `git ls-files Note` 检查结果：`Note/` 当前被跟踪文件总数为 269，非 `.md` 文件数量为 0。
- `git ls-files --others --exclude-standard Note` 检查结果：未忽略的未跟踪 `Note/` 文件数量为 0。
- `git ls-files --others --ignored --exclude-standard Note` 检查结果：6233 个 `Note/` 本地文件处于忽略状态。
- 暂存区检查结果：新增的 `Note/` 文件全部为 `.md`，非 Markdown 文件只从 Git 索引移除，本地文件不删除。

## 代码变更摘要

- `.gitignore`：收敛 `Note/` 规则，只允许 Markdown 文件被跟踪。
- `.gitignore`：忽略 `Note/` 中的嵌套 Git checkout，避免误提交为子模块。
- `Problems/Problem20260606204616.md`：记录本次 Git 忽略策略调整。
