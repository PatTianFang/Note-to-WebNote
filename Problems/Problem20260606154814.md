## 任务目标

将当前 GitHub Pages 风格的静态笔记发布流程改造为 Cloudflare Pages + R2 方案：前端继续由静态 HTML/CSS/JS/JSON 托管，PDF 不再进入 GitHub 仓库，而是由本地发布脚本上传到 Cloudflare R2，并在生成的文章页中引用 R2 自定义域名 URL。

## 思考过程

当前项目的关键链路是 `Publish.py` 扫描 `Note/`，生成 `WebNote/PatTianFang.github.io/posts/` 下的文章 HTML，并更新 `data/posts.json`。原逻辑还会把 PDF 复制到 `WebNote/PatTianFang.github.io/pdfs/`，这正是 GitHub 上传限制和仓库膨胀的来源。

迁移时保持前端零构建、零框架的现有设计，只改变 PDF 的存储和链接来源。采用本地 `wrangler` 命令上传 R2，避免引入额外 Python SDK 和密钥文件；脚本通过环境变量读取 bucket 和公开域名，避免把用户域名写死进代码。

## 遇到的问题

- 项目已有生成文件和子仓库未提交状态，不能回退或清理非本次改动。
- 当前模板下载链接仍是 `href="#"`，迁移到远程 PDF 后需要和嵌入地址保持一致。
- 本地环境暂未配置真实 Cloudflare 账号、R2 bucket 和自定义域名，因此不能执行真实上传验证。

## 解决方法

- 修改 `Publish.py`，删除发布目录内 PDF 复制逻辑，改为使用 `wrangler r2 object put` 上传。
- 生成 HTML 时把嵌入和下载链接都指向 `WEBNOTE_R2_PUBLIC_BASE_URL` 下的 `pdfs/<category>/<filename>`。
- 对 URL path 做百分号编码，兼容中文、空格和 `+` 等字符。
- 在缺少 R2 环境变量或 `wrangler` 时让脚本明确失败并停止，避免生成错误链接。
- Wrangler 4.x 测试时发现 `r2 object put` 会提示 local resource，因此上传和删除命令必须显式添加 `--remote`，确保操作 Cloudflare 远端 R2。
- 如果任一 PDF 上传失败，跳过 `posts.json` 更新，避免把上传失败误判为文章删除。
- 将 `WebNote/PatTianFang.github.io/pdfs/` 加入子仓库 `.gitignore`，避免后续误提交。

## 验证结果

- `python -m py_compile Publish.py` 通过，确认脚本语法有效。
- 缺少 `WEBNOTE_R2_BUCKET` 和 `WEBNOTE_R2_PUBLIC_BASE_URL` 时运行 `python Publish.py`，脚本明确报错并输出“同步未完成”，未继续生成错误 URL。
- 函数级校验确认中文、空格、`+` 路径会被编码为浏览器可访问 URL；同时修复了公开域名末尾带 `/` 时产生双斜杠的问题。
- `static.patfang.xyz` 解析到 Cloudflare，`wrangler` 已登录，`webnote-pdfs` bucket 存在。
- 使用 `wrangler r2 object put --remote` 上传 `Latex语法.pdf` 到 `webnote-pdfs/pdfs/MathNote/Latex语法.pdf` 成功。
- `curl.exe -I https://static.patfang.xyz/pdfs/MathNote/Latex%E8%AF%AD%E6%B3%95.pdf` 返回 `200 OK`，`Content-Type: application/pdf`，`Content-Length: 26463`。
- 设置 `WEBNOTE_R2_BUCKET=webnote-pdfs` 和 `WEBNOTE_R2_PUBLIC_BASE_URL=https://static.patfang.xyz` 后运行 `python Publish.py`，当前 `Note/` 下 PDF 全部上传成功，生成页面和 `posts.json` 更新成功。
- 抽查 `posts/MathNote/Latex语法.html`，嵌入和下载链接均指向 `https://static.patfang.xyz/...`。
- 抽查 `https://static.patfang.xyz/pdfs/Reinforcement%20Learning%20Note/01-%E5%A4%9A%E8%87%82%E8%B5%8C%E5%8D%9A%E6%9C%BA.pdf` 返回 `200 OK`，`Content-Type: application/pdf`。
